# Acend

Marketing site for Acend, a Solana trading platform. The page keeps Acend’s product, images, and wordmark, and sets them in the same type, color, and spacing system as cursor.com.

Open `index.html` in a browser. Join waitlist opens `/waitlist`. Sign in opens a beta notice.

The signup page talks to Waitlister through `/api/waitlist`. Set `WAITLISTER_API_KEY` and `WAITLISTER_WAITLIST_KEY` on the host. The key is not sent to the browser.
